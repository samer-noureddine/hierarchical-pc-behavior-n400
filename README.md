# Reproducing the Simulations

To reproduce the simulation data and figures reported in the paper, run:

``` bash
python run_simulations.py
```

`run_simulations.py` runs the simulations and generates the
corresponding figures and output data.

## Statistical Analysis

The simulation outputs used for statistical analyses are provided in the
`simulation_csv_files/` directory. These CSV files can be used directly
to reproduce the statistical analyses reported in the paper.
